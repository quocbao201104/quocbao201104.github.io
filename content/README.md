# BAO.OS Memory Content

This folder is the versioned knowledge corpus behind BAO.OS. It is also public repository content, so every file must be safe to read directly on GitHub.

As of 2026-08-21, the public BAO.OS deployment runs without live LLM/RAG. The routing, retrieval, redaction, API, and ingestion implementation remain in source, while this Markdown corpus stays useful as the inspectable source of truth and can be re-ingested when the AI backend is enabled again.

## Corpus Rules

- Prefer short, retrieval-friendly sections with repeated project names and aliases.
- Separate **current status** from historical implementation evidence.
- Do not invent users, revenue, request volume, accuracy, adoption, team size, or production scale.
- If a claim comes only from repository structure or code, say it is repository evidence rather than external validation.
- Do not describe a private repository as publicly inspectable.
- Do not store phone numbers, dates of birth, credentials, private infrastructure details, or other unnecessary personal/sensitive data in this public corpus.
- Keep failed or abandoned projects out of the current-project index unless they are intentionally included as retrospectives.
- Preserve Vietnamese names and project-specific identifiers exactly when they matter.
